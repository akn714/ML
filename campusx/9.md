# Machine Learning Development Life Cycle (MLDLC) — Quick Summary

The Machine Learning Development Life Cycle (MLDLC) is a step-by-step process for building a complete machine learning product, from identifying a problem to deploying, testing, and maintaining the model.

The lecture covers 9 main steps.

## 1. Problem Framing
- Define the problem: Identify what needs to be solved, who the customers are, and what the expected output should be.
- Plan the solution: Decide the type of ML task, such as classification or regression, the required resources, and the project budget.

## 2. Data Collection
- Gather data: Collect data from CSV files, APIs, web scraping, databases, or data warehouses.
- Store data properly: Organize the collected data in a suitable format for further processing and model development.

## 3. Data Processing (Data Preprocessing)
- Clean the data: Handle missing values, remove duplicates, correct errors, and deal with outliers.
- Transform the data: Apply techniques such as scaling and formatting so the data is suitable for ML algorithms.

## 4. Exploratory Data Analysis (EDA)
- Understand the data: Use statistics, graphs, and visualizations to discover patterns, distributions, and relationships between features.
- Find data issues: Identify class imbalance, unusual patterns, and correlations that may affect model performance.

## 5. Feature Engineering and Feature Selection
- Feature engineering: Create new features or transform existing ones to help the model learn better. For example, combining related housing measurements into a more useful feature.
- Feature selection: Choose the most relevant features and remove unnecessary ones to reduce training time and improve performance.

## 6. Model Training
- Train multiple models: Apply different ML algorithms to the prepared data because no single algorithm works best for every problem.
- Learn patterns: Train the algorithms using the data so they can make predictions on new, unseen examples.

## 7. Model Evaluation and Selection
- Evaluate performance: Use suitable metrics, such as accuracy, precision, recall, F1-score, or MAE, depending on the ML task.
- Select and tune the model: Compare candidate models and adjust their hyperparameters to find a model that performs well.

## 8. Model Deployment and Testing
- Deploy the model: Save the trained model and integrate it into an application using an API, website, or mobile app, often hosted on a cloud platform.
- Test the application: Conduct testing, including beta testing with selected users, to collect feedback and identify problems before wider release.

## 9. Monitoring and Optimization
- Monitor the model: Track performance, manage server load, maintain backups, and arrange rollback procedures in case something goes wrong.
- Maintain and retrain: Automate updates and retraining when data changes or model performance declines due to model drift.

## Important Concepts Mentioned in the Lecture

- ETL (Extract, Transform, Load): A process for extracting data from sources, transforming it, and loading it into a suitable storage system.
- API (Application Programming Interface): Allows an application to send input to a deployed model and receive its prediction.
- Ensemble learning: Combines multiple models to potentially achieve better performance. Examples include bagging and boosting.
- Hyperparameter tuning: Adjusts model settings to improve its performance.
- Model drift: Occurs when changes in real-world data cause a model's predictions to become less reliable over time.
- Automation: Helps automate deployment, monitoring, retraining, backups, and other recurring tasks.

## Final Recap

| Step | Main Purpose |
|---|---|
| 1. Problem Framing | Define the problem |
| 2. Data Collection | Gather and store data |
| 3. Data Processing | Clean and prepare data |
| 4. EDA | Understand patterns in data |
| 5. Feature Engineering & Selection | Improve input features |
| 6. Model Training | Train ML algorithms |
| 7. Evaluation & Selection | Compare and optimize models |
| 8. Deployment & Testing | Make the model usable |
| 9. Monitoring & Optimization | Maintain and improve the model |

## Key Takeaway

Building a machine learning product is not just about training a model and achieving high accuracy. It involves the entire process of collecting data, preparing it, selecting the right model, deploying it, and continuously monitoring its performance.
